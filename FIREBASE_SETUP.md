# DentalCare HMIS — Complete Firebase Configuration Guide

This step-by-step manual guides you through setting up a real Firebase project for the DentalCare Digital Patient Record & Prescription Management System.

---

## Step 1: Create Firebase Project

1. Go to the [Firebase Console](https://console.firebase.google.com/).
2. Click **Add project** (or **Create a project**).
3. Name your project: `dentalcare-hmis` (or your preferred name).
4. (Optional) Google Analytics can be enabled or disabled according to your preference.
5. Click **Create project** and wait for provisioning to complete.

## Step 4: Configure Authorized Domains

Under **Authentication > Settings > Authorized domains**:
1. Ensure `localhost` is listed (enabled by default).
2. If testing over a local network or mobile device, add your computer's local IP (e.g. `192.168.1.5`).
3. Add your production Firebase Hosting domain once deployed.

---

## Step 5: Create Cloud Firestore Database

1. In the Firebase console left sidebar, navigate to **Build > Firestore Database**.
2. Click **Create database**.
3. Choose your database location (e.g. `asia-south1` for India / Mumbai, or standard `us-central1`).
4. Choose **Start in production mode** (our `firestore.rules` file enforces complete security).
5. Click **Create**.

---

## Step 6: Deploy Firestore Security Rules

You can deploy the security rules directly from the project using the Firebase CLI or paste them in the console:

### Option A: Firebase CLI
```bash
firebase login
firebase deploy --only firestore:rules
```

### Option B: Firebase Console
1. Open **Firestore Database > Rules**.
2. Replace all existing text with the contents of `firestore.rules` located in the root of this project.
3. Click **Publish**.

---

## Step 7: Deploy Firestore Indexes

Deploy the composite indexes for querying appointments and patient records:

```bash
firebase deploy --only firestore:indexes
```
Or use the automated query links generated by Firestore in the browser console when running compound queries.

## Step 8: Database Collections Overview

The application utilizes 7 core collections in Firestore:

1. **`users`**: User profiles with roles (`doctor`, `receptionist`, `patient`, `admin`).
2. **`patients`**: Patient demographic data, allergies, systemic history. The document ID is the verified `+91` mobile number (UHID).
3. **`appointments`**: Scheduled visits, statuses (`scheduled`, `checked-in`, `waiting`, `in-consultation`, `completed`, `cancelled`, `no-show`).
4. **`consultations`**: Doctor clinical notes, chief complaints, FDI tooth findings, diagnoses, and treatment plans.
5. **`prescriptions`**: Finalized Rx records containing medication items, dosage instructions, and advice.
6. **`medications`**: Medication master catalog for dropdown selection.
7. **`auditLogs`**: Append-only security audit logs tracking registrations, updates, consultations, and prescription generation/sharing.
8. **`clinicFeedback`**: Usability ratings and feedback from clinic staff.
